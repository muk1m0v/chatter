# Салом 0.1 — первая тестовая сборка

Нативный Android APK на Kotlin + Jetpack Compose. Основной акцент — жёлтый `#FFC400`, светлый фон и тёмный текст. Регистрация в будущей серверной версии будет доступна по телефону или email.

В этой сборке:

- Экран знакомства: имя и выбор телефона/email, проверка формата.
- Четыре вкладки: чаты, контакты, настройки и профиль.
- Демонстрационные собеседники и поиск по чатам.
- Отправка сообщений в локальный чат, сохранение после закрытия приложения.
- Редактирование имени и описания профиля.
- Переключение светлой/тёмной темы, сохранение настройки.
- Жёлтая иконка приложения, название «Салом» в списке приложений.

Подтверждение номера/email, реальные аккаунты, доставка сообщений другим людям, уведомления и звонки ещё не подключены. Демо-данные явно отмечены в интерфейсе. Тестовый профиль не является защищённой учётной записью.

Сборка, установка по USB и запуск:

```powershell
.\tools\build-install.ps1 -Offline
```

APK: `android/app/build/outputs/apk/debug/app-debug.apk`. Для первой загрузки зависимостей уберите `-Offline`.
