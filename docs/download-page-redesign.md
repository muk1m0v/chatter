# Страница скачивания — 14 ноября 2026

Новый дизайн для существующего mukimov.site: светлый тёплый фон, насыщенный жёлтый акцент, крупный заголовок, SVG-логотип, декоративная композиция с телефоном и иллюстрацией личных заметок. Дальше — краткий обзор реальных возможностей, тёмный блок установки и раскрывающиеся ответы на вопросы.

Четыре действующие ссылки скачивания ведут на тот же APK. На мобильных экранах появляется нижняя кнопка скачивания после ухода основной кнопки за пределы экрана. Версия и размер автоматически читаются из публичного version.json; при отсутствии сети остаются исходные значения, скачивание доступно без JavaScript.

Вся страница — один HTML-файл около 26 КБ, без внешних шрифтов, изображений, аналитики, библиотек и бесконечных анимаций. Рисунок интерфейса обозначен как иллюстрация. Не добавлены вымышленные пользователи, отзывы, рейтинги или неработающие функции. Ограничение серверной переписки указано рядом с кнопкой и в FAQ.

Проверены синтаксис JavaScript, уникальность id, внутренние ссылки и четыре ссылки APK. Локальный предпросмотр просмотрен в узком окне Chrome: первый экран, кнопка и тексты видны без горизонтального обрезания. Прямое управление широким окном оказалось заблокировано сообщением `user input was detected in this window; call get_window_state before continuing`; после повторного наблюдения блокировка сохранилась. Поэтому полная визуальная проверка широкого экрана и точных мобильных размеров не заявляется.

Развёртывание `download-page/deploy-page.py` заменяет только index.html атомарно и сохраняет предыдущую страницу в root-приватной резервной копии. Nginx-конфигурация, API каталога, база, APK и Android-приложение этим изменением не затрагиваются.
