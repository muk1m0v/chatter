# Салом 0.3.1 — Smart Search и статус контакта

- Поиск username начинается с первой буквы, без обязательного `@`, без учёта регистра. Совпадение username — по началу, а не по произвольной середине строки.
- Результаты сужаются с каждым символом. Точное совпадение приоритетнее начала username, затем идут имя и номер.
- Поиск одновременно показывает доступные профили и реальные контакты телефона. Поддерживается простая транслитерация кириллицы и игнорирование оформления номера.
- Условия открытия контакта разделены: известный `is_active = true` → чат; `false` → приглашение; отсутствие записи → неизвестный статус, без утверждения, что у человека нет Салом.
- В текущей сборке известен только локальный профиль этого устройства. Совпадение собственного номера открывает Избранное. Серверный каталог аккаунтов, подтверждение номеров и обмен сообщениями между устройствами ещё не подключены. Код условия и тестовый is_active=true не означают, что реальная регистрация других контактов уже проверяется.
- Khayrulloev используется только в автоматических тестах prefix-search и маршрутизации. Фиктивный человек в телефонную книгу или публичные результаты не добавляется, ручное назначение активного контакта отсутствует.
- Короткая переписка теперь прижимается к нижнему краю, сверху остаётся свободный фон. Сохраняется история 0.3.0.

Автотесты: `testDebugUnitTest` — 4 теста, успешно. Проверены K→Kh→Khayr, необязательный @, отсутствие совпадения username по середине, транслитерация, телефонный поиск, CHAT/INVITE/UNKNOWN.
