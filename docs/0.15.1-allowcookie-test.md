# SALOM 0.15.1 AllowCookie test build

This is a private test build. Do not publish it as a final release until the owner has completed Android/Windows device testing.

## Build artifacts

- Android: `outputs/SALOM-0.15.1-AllowCookie-test.apk` (debug-signed with the same debug certificate as the saved 0.14.7 test APK).
- Windows: `outputs/SALOM-0.15.1-AllowCookie-Setup.exe` (self-contained per-user setup; unsigned).

The Android release build remains gated on the protected release-signing profile. The historical release key must not be replaced for a public upgrade. The Windows setup installs under `%LOCALAPPDATA%\Programs\SALOM`, creates Start menu and desktop shortcuts, and does not require administrator rights. Windows WebRTC needs the Microsoft Edge WebView2 Runtime; if it is not present, install the Evergreen Runtime first.

## Android checks

1. Install or update the APK and sign in with the existing Google account.
2. Send text and a photo/file in both directions; confirm messages arrive without reopening the chat.
3. Start a voice/video call from Android to Windows and from Windows to Android; accept, decline, hang up, mute, speaker, and camera toggle.
4. Try calls on Wi-Fi and across Wi-Fi/mobile data. If peers do not connect across different networks, configure and verify TURN credentials on the API host.
5. Background the app and verify incoming-call notifications and the ongoing call notification.

## Windows checks

1. Install the Setup.exe and launch SALOM; complete Google sign-in.
2. Verify the chat list updates live while another user sends a message.
3. Send and download a photo/file; check the saved file opens correctly.
4. Minimize SALOM and verify a new-message tray notification; restore it from the tray menu.
5. Test incoming and outgoing voice/video calls, camera and microphone permission, mute, camera toggle, and hangup.

Real-device and cross-network checks are intentionally left to the owner and friend. This file records no physical test as passed.
