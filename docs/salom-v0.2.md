# Салом 0.2.0

## Интерфейс

- Удалены вымышленные собеседники и все подписи «тест»/«демо» из основного приложения.
- Старые демонстрационные чаты больше не отображаются. Профиль и собственные заметки в Избранном сохраняются при обновлении.
- Компактная шапка, жёлтый акцент, нижнее меню со скруглением, аккуратные пустые состояния.
- Переключение вкладок с коротким Crossfade 140 мс; используются системные настройки масштаба анимаций.
- Системные панели подстраиваются под светлую/тёмную тему.

## Контакты

- Настоящие имена и номера читаются из Android Contacts Provider только после разрешения READ_CONTACTS.
- Чтение выполняется в Dispatchers.IO, вне потока интерфейса. Список имеет стабильные ключи и ленивое отображение.
- Поиск по имени и номеру, удаление повторов одного номера одного контакта, ручное обновление.
- Отказ в разрешении и возврат из системных настроек обрабатываются отдельно; телефонная книга на сервер не отправляется.
- Карточка открывает запись в системной телефонной книге. Принадлежность контакта к пользователям Salom не проверяется: сервер аккаунтов и переписки ещё не подключён.

## Скорость и сборка

- По умолчанию скрипт собирает release с R8 и resource shrinking.
- Для возможности установить обновление поверх 0.1 сохранена существующая локальная подпись debug keystore. Это не настройка подписи для публикации в магазине.
- Не добавлены WebView, сетевые библиотеки, постоянные таймеры, загрузка фотографий контактов или бесконечные анимации.
- Быстрая работа на всех устройствах не гарантируется; результаты проверки конкретного Itel добавляются после установки.

```powershell
.\tools\build-install.ps1 -Offline
```

Для отладки: `-Variant debug`. Выходной APK: `android/app/build/outputs/apk/release/app-release.apk`.

Реальное подтверждение телефона/email, серверная доставка, push и звонки пока не реализованы. В 0.2 доступна адресная книга телефона и локальное Избранное. Чужие контакты не выдаются за зарегистрированные аккаунты или активные переписки.

Короткий замер восьми переходов между вкладками: 88 отрисованных кадров, 4 janky frame (4,55%), медиана 13 мс, p95 46 мс по dumpsys gfxinfo. Это ограниченная проверка, не полноценный benchmark и не гарантия отсутствия пропусков кадров. Для сравнения с 0.1 сопоставимый benchmark не выполнялся. Холодный запуск процесса не равен запуску после перезагрузки устройства; системные кеши могли быть прогреты.

Метод оптимизации соответствует рекомендациям [Android Compose performance](https://developer.android.com/develop/ui/compose/performance); чтение контактов — [Android Contacts Provider](https://developer.android.com/identity/providers/contacts-provider/retrieve-names).
