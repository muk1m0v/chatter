# Салом 0.4.0 — общий каталог username

## Исправленная причина

В 0.3.1 поиск знал только профиль на текущем устройстве. Поэтому username другого человека невозможно было найти независимо от правильности написания. В 0.4.0 профили синхронизируются с общей SQLite-базой отдельного API на сервере.

- HTTPS API: `https://mukimov.site/salom/api/`.
- Профиль публикует только отображаемое имя и username. Телефоны, email, описание, адресная книга и локальные сообщения в каталог не передаются.
- Username уникален без учёта регистра, поиск идёт по префиксу с необязательным `@`. Нельзя занять уже используемый username или изменить профиль с ключом другого устройства.
- Секретный 256-битный ключ хранится в приватных настройках Android; сервер хранит только SHA-256 ключа. Идентификатор — случайный UUID, а не IMEI или номер телефона.
- Синхронизация происходит при запуске и изменении профиля. Сохранение занятого имени не меняет локальные поля. Ошибки сети видны пользователю; они не маскируются пустой выдачей.
- Запросы поиска выполняются в фоне с задержкой 200 мс при вводе; устаревшие корутины отменяются.

Обоим участникам нужно обновить APK поверх существующей установки и открыть его с интернетом. Если профиль уже имеет username, он синхронизируется автоматически; иначе username задаётся в редакторе профиля.

## Границы этой версии

Это исправление глобального поиска. Подтверждение телефона/email, восстановление аккаунта на другом устройстве, серверная доставка сообщений и push ещё не реализованы. Профиль привязан к текущей установке приложения; не удаляйте приложение для обновления. У чужого найденного профиля отправка сообщений пока отключена с явным пояснением. Избранное продолжает работать локально.

Поскольку телефонные номера ещё не подтверждены на сервере, зарегистрированный username не выдаётся за проверенную привязку к номеру из контактов.

## Сервер

- FastAPI/Uvicorn в отдельном окружении `/opt/salom-api/.venv`, отдельный пользователь и systemd-сервис `salom-api`.
- Только loopback `127.0.0.1:18731`, наружу API доступен через существующий Nginx/HTTPS.
- База `/var/lib/salom-api/directory.sqlite3` под владельцем сервиса, каталог 0700; WAL и транзакции для уникальности.
- Размер запроса ограничен, поиск требует авторизации, создание новых профилей ограничено по IP, запросы — по ключу.
- В Git сохраняются исходники и lock-файл, но не ключи устройства, база, виртуальное окружение или пользовательские данные.
- Скрипт развёртывания делает резервную копию конфигурации и существующей SQLite-базы перед обновлением. Новая база не является частью Git-резервной копии.

## Проверки

`backend/smoke_test.py` прошёл через публичный HTTPS: поиск второго аккаунта по профилю первого, префикс и регистр, уникальность username, запрет чужого обновления, отказ без авторизации, распространение переименования. Все созданные этим тестом профили удалены.
